# Skill supplement source review

Reviewed: 2026-08-14

## Product decision

The skill-supplement branch is a navigation layer, not a single curriculum. It groups four different investment types:

1. role-specific screening practice;
2. applied tools and demonstrable projects;
3. competitions used to build evidence;
4. longer-cycle professional qualifications.

These options are not peers in cost, duration, or hiring signal. The note must direct learners back to the target role's JD and recruitment process before recommending any of them.

## Primary sources

- [LeetCode SQL 50](https://leetcode.com/studyplan/top-sql-50/) — first-party SQL interview-practice plan.
- [NumPy Learn](https://numpy.org/learn/) — contributor-developed or community-vetted learning resources.
- [pandas Getting Started](https://pandas.pydata.org/docs/getting_started/index.html) — official tutorials for tabular-data workflows.
- [scikit-learn User Guide](https://scikit-learn.org/stable/user_guide.html) — official reference for machine-learning algorithms and model evaluation.
- [Pro Git](https://git-scm.com/book/en/v2) — official Git book.
- [GitHub Skills](https://skills.github.com/) — first-party interactive GitHub courses.
- [Kaggle Competitions](https://www.kaggle.com/competitions) — first-party competition catalogue.
- [ACCA Qualification](https://www.accaglobal.com/gb/en/qualifications/glance/acca/overview.html) — qualification-owner overview.
- [CQF overview](https://www.cqf.com/about-cqf/qualification/overview) — qualification-provider overview.

## Copyright boundary

“Investment Banking 400 Questions” and “green book” are used as informal names for third-party interview-preparation materials. The product may explain what such question banks are for, but must not host or link to unauthorized copies. Learners should verify the current interview format through employer materials and obtain any commercial resource through its authorized publisher.
