# 面试准备与复盘

## 第一步：研究公司与岗位

先看公司官网的 Values、Missions、业务介绍和近期信息，再拆解 JD。提取 4–6 个关键词。至少要知道：岗位实际做什么、服务谁、近期有什么挑战，以及公司想找怎样的人。

研究不是为了背公司资料，而是找到你的动机和经历与岗位真正相关的地方。

<a id="concept-interview-question-map"></a>
## 第二步：建立四类问题地图

### 1. Motivation Questions

常见问题包括 Why company、Why me、Why this role、Why this industry，以及香港岗位中可能出现的 Why Hong Kong。回答时要连起三件事：

1. 公司或岗位的具体特点；
2. 你过去形成兴趣的真实经历；
3. 你希望继续发展的方向。

“贵公司平台很好”不是动机。要说清楚，这家公司和你有什么关系。

### 2. Behavior Questions

准备 4–5 个 STAR-R 故事，覆盖学习敏捷度、主动性、协作、冲突、失败或压力。回答时根据公司文化和 JD 调整重点，但不要捏造经历。

### 3. Technical / Role-specific Questions

准备多少由岗位决定。数据与技术岗位可能考 SQL、编程、产品思维或案例；金融岗位可能问市场与宏观经济；综合 MT/GT 也要说清目标部门在做什么。不要看到“Graduate Trainee”就忽略专业准备。

### 4. Resume Questions

面试官可以追问简历上的任何一句话。你应能解释目标、行动、取舍、结果口径和复盘。把简历经历重新映射到公司文化关键词和 JD，可以帮助你找到最相关的故事，而不是临场搜索记忆。

<a id="concept-spoken-star"></a>
## 第三步：形成自己的表达主线

完成上面的准备后，提取 4–5 个有证据的 Strengths，例如 learning agility、self-motivation、communication 或 analytical thinking。Strength 不是形容词，而是多个故事里反复出现的行为。

接着准备：

- **60–90 秒自我介绍：** 现在的方向、关键经历、为什么来到这个岗位。
- **每个故事的 30 秒与 2 分钟版本：** 适应不同面试节奏。
- **你的反问：** 团队挑战、对新人的期待、成功标准或岗位发展。

反问不是表演。认真听完对方的回答，再自然追问，或补充一句与你相关的连接。

## 第四步：做有反馈的模拟面试

面试前两天可以使用右侧“模拟面试”进行陪练，尤其适合高频使用英语面试的同学。练习时：

1. 输入目标岗位、公司与本轮重点。
2. 第一次不看提示，限时完整回答。
3. 检查是否回答问题、结构是否清楚、证据是否具体、动机是否真实。
4. 根据反馈重答一次；第二次应该更清楚，而不是更长。
5. 最后脱离文字，以自然口语再说一遍。

AI 可以生成追问、检查结构，但也可能误解公司或给出模板答案。公司信息要回到官方来源核实，回答也要保留自己的语言。

<a id="concept-interview-review"></a>
## 第五步：面试后立即复盘

记录实际问题、回答要点、卡住的位置、面试官追问、现场观察和下一次行动。区分三类信号：

- **可立即改善：** 回答太绕、案例不具体、公司研究不足。
- **需要长期补足：** 多次暴露同一技能缺口。
- **匹配度信号：** 你是否真的喜欢工作内容和团队交流方式？

面试不只是公司评估你。你感到不适、感兴趣或好奇的地方，也是之后做选择的依据。

## 本节行动

选择一个真实岗位，完成公司/JD 关键词、5 类 Motivation、5 个 STAR-R 故事、专业题清单、自我介绍和 3 个反问。然后完成一轮标准模拟面试，并根据反馈重答最薄弱的问题。
