# 個人主頁

個人主頁是集中展示你專業形象和職業信息的頁面，用來集中呈現你的職業發展方向、經歷、項目和聯繫方式。它不同於項目集：項目集深入展示作品，而個人主頁則負責把你的簡歷、LinkedIn、GitHub、文章和項目組織到同一個地方，提供一個全面的概覽。

## 什麼時候值得做

如果你的材料分散在多個平台，或者你申請的崗位特別關注作品、寫作、技術實現與個人表達，那麼個人主頁會非常有幫助。如果目前你只有一份簡歷和一個項目，先把這些內容打磨好也完全可以，個人網站不是求職的必備項目。

## 首頁核心要素

當招聘者快速瀏覽你的網站時，最好能一眼看懂：
*   你是誰，目前關注什麼方向；
*   最值得看的經歷或代表項目是什麼；
*   你的能力有什麼證據；
*   怎樣查看簡歷或聯繫你。

首頁可以由簡短介紹、代表項目、經歷摘要、簡歷入口和聯繫方式組成。其他更詳細的內容再按需進入獨立的頁面。

## 優先信息層級與可訪問性

請將信息層級的重要性放在視覺效果之前。每個項目先寫一句結論，再提供圖片和詳情鏈接。導航名稱保持直白，例如 About、Projects、Experience、Writing、Contact。動畫、3D 效果和複雜滾動若拖慢加載速度或遮擋內容，反而會妨礙信息傳達。

移動端適配至關重要。文字能否舒適閲讀、按鈕是否容易點擊、圖片是否溢出、導航是否能順暢開關，這些都比炫酷效果更能影響真實的用户體驗。同時，為確保網站對所有用户都易於訪問，請考慮使用語義化的 HTML、為圖片添加替代文本（alt text），並確保足夠的顏色對比度。

## 選擇搭建與發佈方式

個人主頁通常分成兩步：先決定用什麼方式搭建內容，再選擇合適的發佈方式。工具可以隨時更換，真正值得長期維護的是你的內容結構、項目案例和個人信息。

### 先選擇搭建方式

*   **[Notion](https://www.notion.com/) / 文檔型頁面：** 上手快，適合先整理經歷、項目和文字內容，也方便持續更新。
*   **[Squarespace](https://www.squarespace.com/) / [Webflow](https://webflow.com/) 等網站生成器：** 提供模板和可視化編輯，適合希望快速做出完整個人網站，同時擁有更多排版自由度的人。
*   **AI / Vibe Coding：** 可以通過自然語言生成頁面，再根據反饋持續調整佈局、交互和內容。適合希望擁有更高自由度，或者想順便嘗試網頁開發的人。完成後通常還需要把網站部署到線上，才能生成可以分享給招聘者的鏈接。
*   **自己編寫網站：** 如果熟悉 HTML、CSS、JavaScript 或 React 等技術，也可以從頭搭建。對於軟件開發崗位，這個過程本身也可以成為項目能力的一部分。

### 再選擇發佈方式

如果使用 Squarespace、Webflow 這類平台，通常可以直接在平台內發佈網站。

如果通過 Vibe Coding 或自己寫代碼生成網站，則可以部署到：

*   **[GitHub Pages](https://pages.github.com/)：** 適合靜態個人主頁和項目集，可以直接從 GitHub 倉庫發佈。
*   **[Vercel](https://vercel.com/)：** 適合 React、Next.js 等現代前端項目，也支持連接 GitHub 倉庫後自動部署。
*   **[Netlify](https://www.netlify.com/)：** 適合靜態網站和前端項目，可以連接代碼倉庫並持續更新部署。

## 可信、隱私與安全

*   公開郵箱可以使用專門的求職郵箱，避免泄露私人信息；
*   簡歷下載版刪除不需要公開的住址、電話或證件信息；
*   分享項目數據前，務必確認權限並進行脱敏處理，避免泄露機密；
*   外部鏈接使用清楚的文字描述，並定期檢查是否失效；
*   自定義域名、HTTPS 加密和訪問統計均為可選，但能顯著提升專業度和安全性；
*   切勿在網頁代碼中直接放置 API Key、密碼或私密文件。

## 發佈前檢查與維護

發佈前，請進行一次徹底的檢查。在手機和電腦上分別測試，從首頁導航至項目、簡歷和聯繫方式。隨後，將鏈接分享給朋友，請他們描述你網站傳達的信息重點和視覺效果，提供建議。

保持網站內容的時效性。定期檢查失效鏈接，並更新你的進展。

如果選擇 GitHub Pages，可以參考 [GitHub 官方 Quickstart](https://docs.github.com/en/pages/quickstart)。它支持從倉庫分支發佈靜態網站，也適合以後逐步更新。
