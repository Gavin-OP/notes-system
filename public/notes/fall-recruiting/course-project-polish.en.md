# Turn a Course Project into Career Evidence

A course project should not be dismissed simply because it began as an assignment. If it shows how you understood a problem, applied a method, and produced a result, it can become useful evidence in a resume or portfolio.

## From assignment to portfolio piece

Add the context first: why was the problem worth solving? Then explain your responsibility, method, important choices, and result. For group work, separate your own contribution from the team's overall output.

## Make it readable

Organize the files, remove irrelevant drafts, and add a README, chart explanations, and essential run instructions. Be honest about limitations and explain what you would improve next. A complete and credible process is usually more persuasive than over-polishing the claim.
