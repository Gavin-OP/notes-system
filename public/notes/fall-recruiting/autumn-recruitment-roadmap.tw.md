# 求職定位與行動計劃

每個人的求職節奏不同，目標也不同。有人剛投出申請，有人已經在面試，也有人到春天才遇到合適的機會。只要提前為自己做好規劃、掌握大致節奏，就無需和別人比較、也無需焦慮。

## 先看全局節奏

下面是常見的應屆生求職週期參考。它不是統一日曆，也不是“錯過某個月就來不及”的倒計時。

| 階段 | 主要行動 |
| --- | --- |
| 夏季至初秋 | 大型 Graduate Programme 陸續開放；簡歷、LinkedIn、項目展示和基礎技能可以同步準備 |
| 秋季至年末 | 投遞較集中，OT、VI、性格測試、面試和 Assessment Centre 可能交錯出現 |
| 年初至春季 | 後續面試與 Offer 繼續推進，也會出現新一批滾動崗位和補招機會 |
| 春季至夏季 | 仍有部分春季招聘活動、滾動崗位和部分專項計劃，可以繼續投遞與面試 |

每個行業、公司和項目都有自己的節奏，有些崗位還會滾動審閲、招滿即止。最可靠的時間來自公司當年的招聘頁面和學校就業平台。即使身邊的人已經進入下一輪，也不代表你的機會窗口已經關閉。

## 如何做全局規劃

計劃可以先從三個現實問題開始：
- 距離希望入職還有多長時間？
- 目前的精力能同時支撐哪些準備？
- 前期準備需要花費多長時間？

如果希望下一年秋季進入工作或 Graduate Programme，從今年的 7-8 月開始就可以查看招聘窗口，並按“提前約一年瞭解和準備”來做保守規劃。部分項目會在入職前很早開放，開放幾個月後便可能截止；等到臨近畢業才第一次查看，容易錯過本可以參與的流程（實際時間仍以目標公司當年的官網為準）。

距離正式求職還比較久（例如，還有 2-3 年時間）時，時間更適合用來探索：嘗試實習、課程項目、社團或其它真實工作機會，慢慢確認自己願意做什麼，也為正式求職時留下可講述的證據。

精力同樣是一種資源。先做好最接近“下一次機會”的事情，例如即將截止的申請、最重要的材料或下一場面試；長期技能訓練和額外項目則放在比較穩定的時段推進。瞭解自己的做事節奏、保持良好的狀態，才能抓住最寶貴的機會、提高求職的成功率。

<a id="concept-target-role"></a>
## 確定想投遞的公司和崗位

關於這個問題，可以從四個角度去思考：

- **我願意做什麼：** 可能是喜歡具體工作，也可能是喜歡某個行業、團隊氛圍、公司文化或生活地點。
- **我適合做什麼：** 哪些經歷已經積累了證據？自己的性格、思考方式和協作習慣更適合怎樣的工作？
- **機會通向哪裏：** 這個崗位能學到什麼，發展路徑如何，積累的能力以後還能去哪些方向？
- **哪些差距來得及補：** 有些能力可以通過項目和練習快速加強，有些則適合放進更長期的計劃。

瀏覽一些真實 JD，把要求拆分進“我已有相關經驗和證據、值得補強、目前先放一放”三欄。經驗和證據可以來自課程、項目、實習、社團或兼職，能自然講清自己的參與和收穫就很好。

剛開始時採取海投的策略，也是非常正常的。等 OT 和 VI 排隊到來，興趣不高的崗位往往最考驗臨場編 Motivation 的功力、也會自動被排在後邊。投遞、交流和麪試會帶來新的信息，也是雙向篩選，這個過程同樣會幫你梳理清自己真正想抓住的機會。

<a id="concept-recruitment-timeline"></a>
## 把時間線變成行動

求職可以分成四個相互重疊的階段：

- **準備期：** 簡歷、LinkedIn、項目集、個人主頁和崗位需要的基礎技能。
- **集中投遞期：** 網申、OT、VI、性格測試和流程管理。
- **筆面試期：** 公司與崗位研究、模擬面試、線下面試和 Coffee Chat / Networking。
- **Offer 決策期：** 核實條件、比較崗位；暫時沒有合適結果時，也可以從反饋中調整方向。

這些階段會自然重疊。材料達到可以溝通的狀態，就可以開始關注和申請合適崗位；進入面試後，新的機會依然值得留意。每次真實反饋都會讓下一版簡歷、下一次申請和下一場面試更有方向。
