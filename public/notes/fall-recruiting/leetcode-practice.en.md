# LeetCode

Check the target role before committing to LeetCode. Software, data, quantitative, and some analytics processes may use coding or SQL tests; many other roles will not.

Choose the language used in the assessment and begin with common patterns rather than random difficulty. For coding, practise arrays, strings, hash maps, sorting, two pointers, stacks, queues, trees, graphs, and basic dynamic programming as relevant. For analytics roles, LeetCode's database problems can cover joins, aggregation, window functions, subqueries, and date logic.

After each problem, record the pattern, the mistake, and a clearer solution. Practise explaining assumptions, complexity, and edge cases aloud. Consistent, role-matched practice is more useful than chasing a large solved count.
