# LeetCode

LeetCode 不只包含算法题，也可以直接练习 SQL。是否加入这条分支，应由目标岗位的 JD、笔试形式和面试反馈决定，而不是因为“秋招都要刷题”。

## 先确定题型

数据相关岗位可以从 LeetCode 的 SQL 题开始，覆盖查询、聚合、连接、子查询和窗口函数。软件或算法岗位再根据要求练习数组、字符串、哈希表、树、图和动态规划等题型。

## 练习过程比题量重要

每道题记录：如何识别题型、第一次卡在哪里、最终思路、复杂度或 SQL 逻辑，以及一周后能否独立重做。不要把看懂答案算作掌握。

## 建立小而稳定的计划

从目标岗位高频题型中选 20–30 题，先完成基础题，再逐步加入计时。每周复做错题，比无限增加新题更有效。面试前练习口头解释思路，不要只追求代码通过。
