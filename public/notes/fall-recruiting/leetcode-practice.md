# LeetCode

LeetCode 不只包含算法题，也可以直接练习 SQL。这条分支是否适合你，可以看看目标岗位的 JD、笔试形式和面试反馈。“秋招都要刷题”听起来声势浩大，实际还是具体岗位说了算。

## 先确定题型

数据相关岗位可以从 LeetCode 的 SQL 题开始，覆盖查询、聚合、连接、子查询和窗口函数。软件或算法岗位再根据要求练习数组、字符串、哈希表、树、图和动态规划等题型。

## 过程比题量更能留下东西

做题时可以留意：怎样识别题型、最初卡在哪里、最终思路、复杂度或 SQL 逻辑，以及过一阵能否独立重做。看懂答案是理解的开始，能够重新推出来才会逐渐变成自己的能力。

## 建立适合自己的节奏

可以从目标岗位的高频题型和基础题开始，熟悉后再逐步加入计时。隔一段时间回看错题，通常比一直增加新题更能发现进步。面试前也可以练习口头解释思路，让“代码通过”和“讲得清楚”一起成长。
