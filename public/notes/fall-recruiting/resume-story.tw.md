# 簡歷打磨與經歷表達

簡歷就像你職業故事的「預告片」，它要快速回答三個核心問題：你做了什麼，你貢獻了什麼，以及因為你，事情發生了什麼變化。一份有說服力的簡歷，能讓招聘者在短時間內看到你的潛力與價值。

<a id="concept-job-description-mapping"></a>
## 從 JD 找到自己的證據，客製化你的簡歷

在開始寫簡歷前，先仔細閱讀目標職位的 Job Description (JD)。把它拆解成三類資訊，幫助你找到最相關的經歷：

-   **工作內容：** 入職後實際要解決什麼問題？需要完成哪些任務？
-   **能力要求：** 職位對技術、分析、溝通、協作或語言能力有什麼具體要求？
-   **組織語境：** 公司強調哪些價值觀 (Values)、使命 (Missions) 和工作方式？

看到核心要求時，可以問自己：「我的哪段經歷和它有關？」暫時沒有直接證據的關鍵詞，可以先留待日後發展，避免硬塞進簡歷。

一份簡歷很難同時照顧所有職位。你可以根據職位要求準備不同版本，調整經歷的順序、篇幅和表達重點。它們都來自同一組真實經歷，在檔案名稱或職位追蹤表中標清用途，會更容易管理。

如果你的幾段實習或專案來自不同公司和行業，可以嘗試找到貫穿其中的核心能力，比如分析問題、理解用戶、推動產品、快速學習和跨團隊溝通。看似零散的經歷，往往也藏著一條很有個人特點的主線。

## 打造有說服力的經歷描述

本節重點在於調整資訊順序與表達方式，但經歷本身仍須真實。讓你的簡歷能回應「公司文化 + JD」：

-   留意公司文化與 JD 反覆強調的關鍵詞。
-   為重要關鍵詞找到真實經歷或行為證據。
-   把相關證據提前，把關聯較弱的細節壓縮。
-   確保每點都能自然引導出你樂於回答的追問。

如果職位重視「溝通能力 (communication skills)」，「和誰溝通、遇到什麼難點、怎樣推進、最後發生了什麼」會比簡單一句「溝通能力強」更有畫面感和說服力。

<a id="concept-star-evidence"></a>
### 整理可複用的 STAR 故事

一條完整且有力的經歷描述，通常可以遵循 STAR 原則：Situation (情境)、Task (任務)、Action (行動) 和 Result (結果)。重點放在你的判斷與行動，以及帶來的具體影響。

**弱表達：**

> 參與用戶調研，負責整理數據。

**更強表達：**

> 設計並執行 18 位用戶訪談，將反饋歸納為 4 類關鍵問題，推動團隊調整 onboarding 流程，提升了新用戶轉化率 15%。

在描述中，優先使用具體、有力的動詞，並盡可能量化你的成果。量化成果時，每個數字都應來源清楚、口徑可解釋並提供必要背景，而非僅是堆砌。同時，清晰區分團隊成果與個人貢獻，突顯你在團隊中的獨特價值。

為使每個故事更完整，可考慮補充以下兩點：

-   **Reflection (反思)：** 如果重來一次，你會怎樣改進？學到了什麼？
-   **Role relevance (職位關聯)：** 這段經歷為什麼與當前職位有關？它如何證明你具備職位所需的能力？

建立能代表自己的故事庫。可從快速學習、主動推進、處理分歧、團隊協作、應對失敗或不確定性等主題取材。一個故事完全可以回答不同問題，只需跟著問題調整重點和側重。

## 格式、版本與 ATS 友善

一份專業的簡歷，內容與呈現方式同樣重要。

-   **ATS 友善：** 許多公司使用 Applicant Tracking System (ATS) 來初步篩選簡歷。為確保 ATS 有效識別，請使用標準標題（如「教育背景」、「工作經歷」）、清晰段落結構，並避免複雜圖表、圖片或非常規字體。確保關鍵詞可被解析，但避免過度堆砌。
-   **格式一致性：** 保持字體大小、行距、項目符號及整體版面的一致性。確保所有連結（如 LinkedIn 個人主頁、個人作品集）皆可點擊。
-   **檔案類型：** 除非招聘方另有要求，請一律匯出為 PDF 格式。PDF 能保留排版，避免在不同設備上顯示錯亂。
-   **版本管理：** 針對不同職位客製化的簡歷，務必在檔案名稱中清晰標註（例如「姓名_職位名稱_公司名_簡歷.pdf」），以便管理。
-   **最終檢查：** 除了內容，請仔細檢查日期、時態、標點、錯別字及不必要的行業術語。請朋友、同學或職涯顧問協助審閱，他們可能發現你忽略的細節。

## 簡歷自檢清單

發送簡歷前，請使用此清單快速檢查：

-   [ ] 開頭是否快速呈現目標職位最需要的核心證據？
-   [ ] 每條經歷是否區分了團隊成果與你的個人貢獻？
-   [ ] 每個數字是否來源清楚、口徑可解釋並提供必要背景？
-   [ ] 是否能簡潔、自然地闡述每段核心經歷，並引導出追問？
-   [ ] 簡歷、LinkedIn、自我介紹中的時間與事實是否一致？
-   [ ] 檔案名稱、日期、格式、聯絡方式與版本是否正確無誤？
-   [ ] 簡歷是否 ATS 友善，並避免了複雜圖表與非常規字體？
-   [ ] 是否已匯出為 PDF 格式（除非另有要求）？
