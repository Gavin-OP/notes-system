# 準備簡歷與 Profile

求職材料像同一個人的不同側面：簡歷快速説明匹配度，LinkedIn 幫別人理解你的方向，Cover Letter 補充動機，項目集或個人主頁則接住簡歷放不下的好東西。

## 先建立統一素材庫

可以先把教育、項目、實習、社團和技能經歷放進一個素材庫。每段經歷保留背景、自己的行動、結果、數字口徑和復盤，寫不同材料時再從中挑選。這樣既省時間，也能讓各個版本彼此一致。

## 決定需要哪些材料

- **簡歷：** 招聘流程中最常見的核心材料，也是 Path 的默認分支。
- **LinkedIn：** 適合用來建立職業身份、研究團隊和進行職業交流。
- **Cover Letter：** 崗位明確要求，或需要解釋動機與匹配關係時再準備。
- **項目集：** 有多個作品或項目案例需要系統展示時使用。
- **個人主頁：** 需要集中呈現個人介紹、鏈接、經歷和長期作品時使用。

材料並不是越齊全越好。跟着崗位要求和自己的內容選擇，就已經足夠完整。

## 保持一致但不完全重複

所有材料中的公司、時間、職責和結果需要互相對得上，表達重點則可以不同。簡歷短而直接；LinkedIn 提供方向和上下文；Cover Letter 解釋選擇；項目集展示過程；個人主頁把分散內容組織成穩定入口。
