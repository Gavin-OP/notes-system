# Application Batch Planning

批量投递的价值是稳定增加被看见的机会，而不是让申请数量成为新的 KPI。把相近岗位分组，可以减少重复准备，也能为真正重要的机会保留精力。

## 按相似度分批

将岗位按职责、材料和截止时间分组。共用一份可靠底稿，再针对关键要求做必要调整；明显不合适的岗位不必为了数字勉强加入。

## 为测试和面试留容量

申请会在之后变成 OA、电话和面试。每批留出消化后续流程的空间，并根据回应率和体验调整下一批节奏。
