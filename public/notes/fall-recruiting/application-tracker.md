# Application Tracker

Tracker 的作用是减轻记忆负担。它不需要变成复杂数据库，只要能回答：投了什么、下一步是什么、什么时候需要行动。

## 保留真正有用的字段

公司、岗位、链接、提交日期、当前状态、下一个节点和截止时间通常已经够用。需要时再补联系人、材料版本和简短备注。

## 让状态服务于决定

定期清理已结束流程，标出即将截止和等待跟进的项目。Tracker 应该帮你看清局面，而不是提醒你“还投得不够多”。
