# Using AI to Support Role Discovery

This is not a programming requirement. The idea is to use plain language to build a small tool that reduces repetitive searching and comparison.

First decide whether it is worth the time. It may help if job boards miss related titles, you repeatedly compare the same JD fields, or your spreadsheet is becoming difficult to search. A normal alert and tracker are better when your targets are already clear or when the tool itself starts consuming preparation time.

Start with a tiny version: paste job links or text, extract company, title, deadline, skills, and notes, then filter the saved list. Ask a coding assistant to build one feature at a time, test with sample data, and keep all data in the browser. Avoid automated scraping behind logins and respect site terms, privacy, and rate limits.

Useful later additions include duplicate detection, keyword groups, deadline reminders, and a comparison view. Keep manual editing and export available so the tool never becomes a new source of lock-in.
