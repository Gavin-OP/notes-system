# Resume Version Management

Multiple resumes can serve genuinely different role directions; they should not create a pile of indistinguishable Final_Final files. Keep a stable master and a small number of meaningful variants.

## Name versions clearly

Include direction, language, and date where useful. Record which version accompanied each application so you can retrieve it before an interview.

## Change emphasis, not facts

Ordering, keywords, and detail can respond to the JD while the experience remains truthful and consistent. If one version repeatedly misses the right response, revisit its positioning and evidence.
