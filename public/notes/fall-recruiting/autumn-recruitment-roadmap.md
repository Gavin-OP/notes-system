# 求职定位与行动计划

每个人的求职节奏不同，目标也不同。有人刚投出申请，有人已经在面试，也有人到春天才遇到合适的机会。只要提前为自己做好规划、掌握大致节奏，就无需和别人比较、也无需焦虑。

## 先看全局节奏

下面是常见的应届生求职周期参考。它不是统一日历，也不是“错过某个月就来不及”的倒计时。

| 阶段 | 主要行动 |
| --- | --- |
| 夏季至初秋 | 大型 Graduate Programme 陆续开放；简历、LinkedIn、项目展示和基础技能可以同步准备 |
| 秋季至年末 | 投递较集中，OT、VI、性格测试、面试和 Assessment Centre 可能交错出现 |
| 年初至春季 | 后续面试与 Offer 继续推进，也会出现新一批滚动岗位和补招机会 |
| 春季至夏季 | 仍有部分春季招聘活动、滚动岗位和部分专项计划，可以继续投递与面试 |

每个行业、公司和项目都有自己的节奏，有些岗位还会滚动审阅、招满即止。最可靠的时间来自公司当年的招聘页面和学校就业平台。即使身边的人已经进入下一轮，也不代表你的机会窗口已经关闭。

## 如何做全局规划

计划可以先从三个现实问题开始：
- 距离希望入职还有多长时间？
- 目前的精力能同时支撑哪些准备？
- 前期准备需要花费多长时间？

如果希望下一年秋季进入工作或 Graduate Programme，从今年的 7-8 月开始就可以查看招聘窗口，并按“提前约一年了解和准备”来做保守规划。部分项目会在入职前很早开放，开放几个月后便可能截止；等到临近毕业才第一次查看，容易错过本可以参与的流程（实际时间仍以目标公司当年的官网为准）。

距离正式求职还比较久（例如，还有 2-3 年时间）时，时间更适合用来探索：尝试实习、课程项目、社团或其它真实工作机会，慢慢确认自己愿意做什么，也为正式求职时留下可讲述的证据。

精力同样是一种资源。先做好最接近“下一次机会”的事情，例如即将截止的申请、最重要的材料或下一场面试；长期技能训练和额外项目则放在比较稳定的时段推进。了解自己的做事节奏、保持良好的状态，才能抓住最宝贵的机会、提高求职的成功率。

<a id="concept-target-role"></a>
## 确定想投递的公司和岗位

关于这个问题，可以从四个角度去思考：

- **我愿意做什么：** 可能是喜欢具体工作，也可能是喜欢某个行业、团队氛围、公司文化或生活地点。
- **我适合做什么：** 哪些经历已经积累了证据？自己的性格、思考方式和协作习惯更适合怎样的工作？
- **机会通向哪里：** 这个岗位能学到什么，发展路径如何，积累的能力以后还能去哪些方向？
- **哪些差距来得及补：** 有些能力可以通过项目和练习快速加强，有些则适合放进更长期的计划。

浏览一些真实 JD，把要求拆分进“我已有相关经验和证据、值得补强、目前先放一放”三栏。经验和证据可以来自课程、项目、实习、社团或兼职，能自然讲清自己的参与和收获就很好。

刚开始时采取海投的策略，也是非常正常的。等 OT 和 VI 排队到来，兴趣不高的岗位往往最考验临场编 Motivation 的功力、也会自动被排在后边。投递、交流和面试会带来新的信息，也是双向筛选，这个过程同样会帮你梳理清自己真正想抓住的机会。

<a id="concept-recruitment-timeline"></a>
## 把时间线变成行动

求职可以分成四个相互重叠的阶段：

- **准备期：** 简历、LinkedIn、项目集、个人主页和岗位需要的基础技能。
- **集中投递期：** 网申、OT、VI、性格测试和流程管理。
- **笔面试期：** 公司与岗位研究、模拟面试、线下面试和 Coffee Chat / Networking。
- **Offer 决策期：** 核实条件、比较岗位；暂时没有合适结果时，也可以从反馈中调整方向。

这些阶段会自然重叠。材料达到可以沟通的状态，就可以开始关注和申请合适岗位；进入面试后，新的机会依然值得留意。每次真实反馈都会让下一版简历、下一次申请和下一场面试更有方向。
