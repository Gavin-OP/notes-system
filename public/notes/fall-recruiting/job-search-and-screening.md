<a id="concept-job-search-and-screening"></a>
# 寻找与筛选合适岗位

<a id="concept-search-channels"></a>
## 建立分层的信息渠道

不同渠道解决不同问题：

1. **公司招聘官网：** 核实岗位是否存在、资格要求、截止时间和正式申请入口。
2. **学校就业平台：** 获取校园专属活动、宣讲会与校友资源。
3. **LinkedIn 等职业平台：** 发现岗位、研究团队和联系往届员工。
4. **行业社群与经验平台：** 了解流程和候选人体验，但要核实时间与真实性。

LinkedIn 和公司官网通常值得优先看，但不同岗位会有差异。记录每个渠道带来的有效申请和面试，用自己的数据决定以后把时间放在哪里。

<a id="concept-role-fit"></a>
## 找到适合自己的投递节奏

把岗位要求分成硬门槛、核心能力和加分项，会更容易读懂长长的 JD。加分项少几项很常见；看到似乎不满足的硬门槛时，可以再去官网或招聘方确认它是否真的不可替代。

可以用五个维度为岗位评分：

| 维度 | 要回答的问题 |
| --- | --- |
| 工作内容 | 我是否愿意持续做这些具体任务？ |
| 证据匹配 | 我能否用真实经历回应核心要求？ |
| 学习空间 | 岗位能否让我获得想发展的能力？ |
| 现实约束 | 地点、时间和个人安排是否可行？ |
| 准备成本 | 为进入下一轮需要投入多少时间？ |

有依据地投递，也不等于只投“百分百匹配”的岗位。感兴趣但稍有距离的机会同样值得尝试；与此同时，低意愿岗位带来的 OT、VI 和开放题，也可以结合自己的精力决定是否继续。
