<a id="concept-job-search-and-screening"></a>
# 寻找与筛选合适岗位

<a id="concept-search-channels"></a>
## 建立分层的信息渠道

不同渠道解决不同问题：

1. **公司招聘官网：** 核实岗位是否存在、资格要求、截止时间和正式申请入口。
2. **学校就业平台：** 获取校园专属活动、宣讲会与校友资源。
3. **LinkedIn 等职业平台：** 发现岗位、研究团队和联系往届员工。
4. **行业社群与经验平台：** 了解流程和候选人体验，但要核实时间与真实性。

LinkedIn 和公司官网通常值得优先看，但不同岗位会有差异。记录每个渠道带来的有效申请和面试，用自己的数据决定以后把时间放在哪里。

<a id="concept-role-fit"></a>
## 从海投转向有依据的精投

把岗位要求分成硬门槛、核心能力和加分项。未满足加分项通常不应自动放弃；不满足硬门槛时，则要确认它是否确实不可替代。

可以用五个维度为岗位评分：

| 维度 | 要回答的问题 |
| --- | --- |
| 工作内容 | 我是否愿意持续做这些具体任务？ |
| 证据匹配 | 我能否用真实经历回应核心要求？ |
| 学习空间 | 岗位能否让我获得想发展的能力？ |
| 现实约束 | 地点、签证、语言、时间是否可行？ |
| 准备成本 | 为进入下一轮需要投入多少时间？ |

精投不等于只投“百分百匹配”的岗位。可以保留少量挑战性机会，但不要让低意愿岗位的 OT、VI 和开放题挤占核心申请。

<a id="concept-networking"></a>
## 用 Networking 理解岗位，不是索取答案

面试前，可以礼貌联系往届 MT/GT、校友或相关团队成员，了解：

- 日常工作与招聘文案有哪些差异？
- 新人最常见的挑战是什么？
- 团队真正重视哪些行为？
- 对方当时如何判断自己适合这个岗位？

联系时简单说明你是谁、为什么找对方，再问一个容易回答的具体问题。不要一上来要内推，也不要问完面试题就消失。对方愿意分享是善意，不是义务。交流后记得感谢，有真实进展时可以简单更新。

<a id="concept-coffee-chat"></a>
### Coffee Chat

Coffee Chat 适合了解岗位日常、团队文化和新人挑战。一次聊一两个真正关心的问题即可，不必把交流变成另一场面试。

<a id="concept-alumni-networking"></a>
### 校友与往届生交流

优先联系经历与你接近、或做过目标岗位的人。说明你为什么找到对方，也让对方容易拒绝。交流的目标是补充判断，不是索取标准答案。

<a id="concept-ai-job-search"></a>
## 用 AI 辅助找岗位

AI 可以帮你整理公司清单、扩展岗位关键词和比较 JD，但不能替你确认岗位是否仍开放。最终申请入口、资格要求和截止时间，都要回到公司官网核实。

## 香港校招的额外检查

如果目标是香港岗位，提前确认英语、普通话和粤语的使用场景。粤语不流利不等于没有机会；可以诚实说明自己正在学习，最好能自然说上一两句。具体要求仍以 JD 和招聘方说明为准。

不少 MT/GT 更看重 communication skills、学习速度和对岗位的理解。但数据、量化、工程或特定金融岗位仍可能考 SQL、编程、宏观经济或领域知识，不要把“管培生不考技术”当成规律。

## 本节行动

建立岗位追踪表，至少包含公司、岗位、来源、截止日期、优先级、语言要求、简历版本、当前状态和下一步。选出三份高优先级 JD，并为每份写下：为什么想去、现有证据、最大缺口，以及一位可以礼貌请教的人。
