# 寻找与筛选合适岗位

<a id="concept-search-channels"></a>
## 建立分层的信息渠道

不同渠道解决不同问题：

1. **公司招聘官网：** 核实岗位是否存在、资格要求、截止时间和正式申请入口。
2. **学校就业平台：** 获取校园专属活动、宣讲会与校友资源。
3. **LinkedIn 等职业平台：** 发现岗位、研究团队和联系往届员工。
4. **行业社群与经验平台：** 了解流程和候选人体验，但要核实时间与真实性。

LinkedIn 和公司官网通常值得优先看，但不同岗位会有差异。记录每个渠道带来的有效申请和面试，用自己的数据决定以后把时间放在哪里。

<a id="concept-role-fit"></a>
## 从海投转向有依据的精投

把岗位要求分成硬门槛、核心能力和加分项。未满足加分项通常不应自动放弃；不满足硬门槛时，则要确认它是否确实不可替代。

可以用五个维度为岗位评分：

| 维度 | 要回答的问题 |
| --- | --- |
| 工作内容 | 我是否愿意持续做这些具体任务？ |
| 证据匹配 | 我能否用真实经历回应核心要求？ |
| 学习空间 | 岗位能否让我获得想发展的能力？ |
| 现实约束 | 地点、时间和个人安排是否可行？ |
| 准备成本 | 为进入下一轮需要投入多少时间？ |

精投不等于只投“百分百匹配”的岗位。可以保留少量挑战性机会，但不要让低意愿岗位的 OT、VI 和开放题挤占核心申请。
