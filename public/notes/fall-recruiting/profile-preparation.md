# 准备简历与 Profile

求职材料像同一个人的不同侧面：简历快速说明匹配度，LinkedIn 帮别人理解你的方向，Cover Letter 补充动机，项目集或个人主页则接住简历放不下的好东西。

## 先建立统一素材库

可以先把教育、项目、实习、社团和技能经历放进一个素材库。每段经历保留背景、自己的行动、结果、数字口径和复盘，写不同材料时再从中挑选。这样既省时间，也能让各个版本彼此一致。

## 决定需要哪些材料

- **简历：** 招聘流程中最常见的核心材料，也是 Path 的默认分支。
- **LinkedIn：** 适合用来建立职业身份、研究团队和进行职业交流。
- **Cover Letter：** 岗位明确要求，或需要解释动机与匹配关系时再准备。
- **项目集：** 有多个作品或项目案例需要系统展示时使用。
- **个人主页：** 需要集中呈现个人介绍、链接、经历和长期作品时使用。

材料并不是越齐全越好。跟着岗位要求和自己的内容选择，就已经足够完整。

## 保持一致但不完全重复

所有材料中的公司、时间、职责和结果需要互相对得上，表达重点则可以不同。简历短而直接；LinkedIn 提供方向和上下文；Cover Letter 解释选择；项目集展示过程；个人主页把分散内容组织成稳定入口。
