# 准备简历与 Profile

求职材料不是彼此独立的文件。简历负责快速证明匹配度，LinkedIn 帮别人理解你的方向，Cover Letter 补充动机，项目集或个人主页承载简历放不下的内容。

## 先建立统一素材库

整理教育、项目、实习、社团和技能经历。每段经历保留完整背景、你的行动、结果、数字口径和复盘，再根据不同材料压缩。这样可以减少版本之间的事实冲突。

## 决定需要哪些材料

- **简历：** 所有人都需要，是 Path 的默认分支。
- **LinkedIn：** 适合用来建立职业身份、研究团队和进行职业交流。
- **Cover Letter：** 岗位明确要求，或需要解释动机与匹配关系时再准备。
- **项目集 / 个人主页：** 有作品、分析过程或项目细节需要展示时使用。

不必为了“看起来完整”把所有材料都做一遍。先看岗位要求，再选择能增加有效证据的部分。

## 保持一致但不完全重复

所有材料中的公司、时间、职责和结果必须一致，但表达重点可以不同。简历短而直接；LinkedIn 提供方向和上下文；Cover Letter 解释选择；项目集展示过程。

## 本节行动

建立一张材料清单，标记必需、可选和暂不准备。为每份材料写清使用场景、目标岗位、完成状态和最后检查日期。
