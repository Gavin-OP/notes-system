# 技能補充

技能準備是求職 Path 的一條副線。它可以與職位研究、履歷準備同步進行，卻不需要變成一張每個人都照抄的清單。

## 先從職位訊號出發

值得優先補充的內容，通常會在 JD、網上測試或面試回饋中反覆出現。例如，技術與數據職位可能要求演算法或 SQL；部分金融職位會關注投資、風險或會計知識。看到清晰而重複的訊號，再把相應分支加入 Path，方向會更清楚。

## LeetCode 與金融證書解決不同問題

- **LeetCode** 較適合準備演算法題、SQL 題及有明確技術考核的招聘流程。
- **金融證書** 是一組需要獨立評估的長期選擇。CFA、FRM 與 HKICPA QP 對應不同知識與職業路徑，是否報考應結合目標職位、考試窗口、時間投入與資格要求。

技能副線不用一次全部開啟。可以先處理最接近下一次申請、測試或面試的部分，其餘內容等真實回饋出現後再加入。

## 怎樣判斷是否繼續投入

學習一段時間後，可以回到三個問題：職位真的會用到嗎？現在能否形成可展示或可考核的證據？它會否擠壓更緊迫的申請和面試準備？答案會幫助你決定繼續、暫停，或改用更直接的準備方式。
