# 技能補充：按職位選擇你的技能包

技能準備是求職 Path 的一條副線。LeetCode、投行面試題、比賽、數據工具和金融證書都可以出現在這條線上，但它們不是同一種投入，也不是每個人都要收集的徽章。

## 先判斷自己欠缺哪一種證據

| 類型 | 較常解決甚麼問題 | 可以留下甚麼 |
| --- | --- | --- |
| 職位篩選題庫 | 應對明確的筆試或面試考核 | 做題記錄、知識框架、面試表現 |
| 工具與項目 | 證明自己能用常見工具解決問題 | GitHub 項目、分析報告、可運行程式碼 |
| 比賽 | 在實習經歷較少時補充協作和項目證據 | 作品、排名、過程復盤、團隊故事 |
| 專業資格 | 系統學習專業領域，或滿足特定職業路徑要求 | 考試進度、知識體系、正式資格 |

先從目標職位的 JD、網上測試說明、面試流程和真實回饋找訊號。同一要求反覆出現時再決定投入；如果只因為「其他人都在學」而開一條新線，最容易得到的技能可能是同時打開很多網頁。

## 職位篩選與面試題庫

- **LeetCode：** 適合流程明確考演算法、數據結構、程式碼或 SQL 的職位。SQL 可以先看 [LeetCode SQL 50](https://leetcode.com/studyplan/top-sql-50/)；演算法題是否需要練、練到甚麼程度，仍由職位流程決定。
- **投行 400 問、綠皮書等面試資料：** 更像針對特定招聘流程的知識題庫，而非通用金融能力。先確認目標職位會考甚麼，再透過正版出版物、學校資源或官方招聘資料準備。本平台不提供未經授權的下載連結。

## 數據、機器學習與項目工具

- **Pandas / NumPy：** 數據分析與科學計算的常用工具。可以從 [pandas Getting Started](https://pandas.pydata.org/docs/getting_started/index.html) 和 [NumPy Learn](https://numpy.org/learn/) 開始，把練習放進一個真實數據問題裏。
- **機器學習演算法：** 與其先背一長串模型名稱，不如圍繞數據準備、模型選擇、評估和常見誤區建立框架。[scikit-learn User Guide](https://scikit-learn.org/stable/user_guide.html)可以作為官方索引。
- **Git 與 GitHub：** Git 幫助記錄和協作開發，GitHub 可以展示公開項目、README、提交記錄和協作方式。可以使用 [Pro Git](https://git-scm.com/book/en/v2) 和 [GitHub Skills](https://skills.github.com/) 入門。綠色貢獻圖不是招聘保證；一個說明清楚、能夠運行的項目通常更有解釋力。

## 比賽與項目證據

- **商賽：** 適合練習研究、商業判斷、方案表達和團隊協作。先看比賽主題與交付物是否和目標職位相關，再決定投入。可以繼續閱讀[商賽準備](./business-competition.md)。
- **Kaggle：** 適合數據分析和機器學習實踐，也可以把公開 Notebook、方法說明和復盤變成作品證據。題目與規則以 [Kaggle Competitions](https://www.kaggle.com/competitions) 為準，也可以查看[Kaggle 比賽準備](./kaggle-competition.md)。
- **課程項目：** 不一定要重新開一個大項目。把已有課程作業補上問題背景、方法選擇、結果驗證和清晰說明，也可能比匆忙參加新活動更完整。

## 金融與專業資格

證書屬於較長周期的選擇，不能只用「含金量高不高」判斷。可以先看目標職位是否明確認可、課程是否補足當前知識、考試窗口是否擠壓申請，以及自己是否符合報考和工作經驗要求。

- 投資與研究方向可以了解 **CFA**；風險方向可以了解 **FRM**；會計路徑可以了解 **HKICPA QP、CPA 或 [ACCA](https://www.accaglobal.com/gb/en/qualifications/glance/acca/overview.html)**。
- 量化金融方向還可能遇到 **[CQF](https://www.cqf.com/about-cqf/qualification/overview)**。它與短期刷題不同，需要獨立評估課程內容、費用、數學基礎和目標職位認可度。
- 想比較現有證書分支，可以繼續閱讀[金融證書怎樣選](./finance-knowledge-certificates.md)。

## 最後只作一個選擇

問自己：目標職位最近會用甚麼方式驗證我？如果答案是程式碼測試，就先練題；如果缺少作品，就做項目或比賽；如果職業路徑明確要求資格，再研究證書。暫時沒有清晰訊號時，先把時間留給職位研究、材料和真實申請也完全合理。
