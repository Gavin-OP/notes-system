# 技能補充：按崗位選擇你的技能包

LeetCode、投行面試題、競賽、數據分析工具、金融證書……這些技能的準備，是求職道路上的一條支線。其中一些需要長期積累，學習和培訓過程可能會從正式求職前幾年開始，一直延續到入職以後。每一項技能都需要投入時間和精力，因此，比起儘可能多地學習，更重要的是根據目標崗位判斷：自己究竟需要在求職階段補充哪些技能，以及哪些技能值得優先投入。

## 先判斷自己缺的是哪一種證據

| 類型 | 更常解決什麼問題 | 可以留下什麼 |
| --- | --- | --- |
| 崗位篩選與面試題庫 | 應對明確的筆試或面試考察 | 做題記錄、面試表現 |
| 工具與項目 | 證明自己能用常見工具解決問題 | GitHub 項目、分析報告 |
| 比賽 | 在實習經歷較少時補充協作和項目證據 | 作品、排名、團隊故事 |
| 專業資格 | 系統學習某個專業領域，或滿足特定職業路徑要求 | 考試進度、正式資格 |

先從目標崗位的 JD、筆試/面試流程説明和求職者真實反饋當中找信號。看到同一要求反覆出現，再決定是否投入；如果只因為“別人都在學”而開始技能補充的支線，最容易得到的技能可能是同時打開很多網頁。

## 崗位篩選與面試題庫

- **LeetCode：** 適合流程明確考算法、數據結構、代碼或 SQL 的崗位。算法題是否需要刷、刷到什麼程度，仍由目標崗位和麪試流程決定。常用題庫包括：
  - [LeetCode 75](https://leetcode.com/studyplan/leetcode-75/)：75 道高頻基礎題，適合用 1–3 個月建立常見算法題型框架。
  - [Top Interview 150](https://leetcode.com/studyplan/top-interview-150/)：覆蓋範圍更完整，適合系統準備技術面試。
  - [Top 100 Liked](https://leetcode.com/studyplan/top-100-liked/)：LeetCode 社區中評價較高的 100 道題，適合補充常見面試題型。
  - [Blind 75](https://neetcode.io/practice/practice/blind75)：經典的 75 道算法面試題，適合快速覆蓋核心題型。
  - [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)：在 Blind 75 基礎上擴展到 150 題，並按照 Arrays、Trees、Graphs、Dynamic Programming 等主題分類，適合系統刷題。
  - [SQL 50](https://leetcode.com/studyplan/top-sql-50/)：50 道基礎到中等難度 SQL 題，適合 Data Analyst、BI、Data Science 等會考 SQL 的崗位。
  - [Advanced SQL 50](https://leetcode.com/studyplan/premium-sql-50/)：覆蓋基礎到進階 SQL 的高頻題目，適合需要更深入 SQL 面試準備的人。
  - [30 Days of Pandas](https://leetcode.com/studyplan/30-days-of-pandas/)：針對 Pandas 常見面試內容，適合數據分析和部分數據科學崗位。
  - [LeetCode Study Plans](https://leetcode.com/studyplan/)：LeetCode 官方全部學習計劃的入口，可以再按目標崗位和技能選擇對應題庫。

- **投行面試題、400 Questions、Red Book 等面試資料：** 更像針對 Investment Banking、Private Equity 等特定招聘流程的知識題庫，通常集中在 Accounting、Valuation、DCF、M&A、LBO、Technical Questions 和 Behavioral Questions。不同崗位、公司和招聘階段的考察重點差異較大，因此可以先確認目標崗位的面試流程，再選擇對應材料。常見的正版或官方公開資源包括：
  - [Breaking Into Wall Street – Investment Banking Interview Guide / 400 Questions](https://breakingintowallstreet.com/investment-banking-interview-guide/)：經典的 Investment Banking 面試準備資料，官方 Interview Guide 中包含其 400 Questions Guide，覆蓋常見 Technical 和 Behavioral Questions。
  - [Wall Street Prep – Investment Banking Interview Guide / The Red Book](https://www.wallstreetprep.com/self-study-programs/the-red-book/)：Wall Street Prep 官方面試題庫，包含大量 Investment Banking Technical 和 Behavioral Questions，適合更系統地準備投行面試。
  - [Wall Street Prep – Investment Banking Interview Questions](https://www.wallstreetprep.com/knowledge/top-10-investment-banking-interview-questions/)：免費的常見投行面試題整理，涵蓋 Valuation、DCF、Accounting 等核心 Technical Questions。
  - [Wall Street Prep – Investment Banking Interview Guide](https://www.wallstreetprep.com/knowledge/investment-banking-interview/)：從整體流程介紹 Investment Banking Interview，並梳理 Behavioral 和 Technical Questions 的主要準備方向。
  - [Wall Street Prep – M&A Interview Questions](https://www.wallstreetprep.com/knowledge/ma-interview-questions/)：集中準備 Merger Model、Accretion / Dilution 和 M&A 相關問題。
  - [Wall Street Prep – Private Equity Interview Questions](https://www.wallstreetprep.com/knowledge/25-private-equity-interview-questions-you-must-know/)：適合進一步申請 Private Equity 的同學，涵蓋 PE Technical Questions 和常見面試主題。
  - [Breaking Into Wall Street – M&A Interview Questions](https://breakingintowallstreet.com/kb/ma-and-merger-models/ma-interview-questions/)：官方免費教程，集中講解 Merger Model 和 M&A 面試中的常見問題。
  - [Breaking Into Wall Street – LBO Interview Questions](https://breakingintowallstreet.com/kb/leveraged-buyouts-and-lbo-models/lbo-interview-questions/)：適合準備 LBO、Private Equity 及部分 Investment Banking Technical Interview。
  - [Breaking Into Wall Street – Equity Value & Enterprise Value Interview Questions](https://breakingintowallstreet.com/kb/equity-value-enterprise-value/equity-value-and-enterprise-value-interview-questions-what-to-expect/)：針對 Equity Value、Enterprise Value 及相關 Valuation Questions 的專題練習。
  - [Breaking Into Wall Street – Behavioral Interview Questions](https://breakingintowallstreet.com/kb/interviews/investment-banking-behavioral-questions/)：集中準備 Why Investment Banking、Walk Me Through Your Resume、團隊經歷等 Behavioral Questions。
  - [CFI – Investment Banking Interview Questions](https://corporatefinanceinstitute.com/resources/career/real-investment-banking-interview-questions-form/)：CFI 官方整理的投行面試題，可以用於補充 Accounting、Valuation 和情景類問題。
  - [Macabacus – Learn Finance](https://macabacus.com/learn)：提供 Operating Model、M&A Model、LBO Model 等公開學習材料，更適合理解面試題背後的 Financial Modeling 知識，而不只是背答案。

## 數據、機器學習與項目工具

- **Pandas / NumPy：** 數據分析與科學計算中最常用的 Python 工具之一。Pandas 主要用於表格數據的讀取、清洗、轉換和分析，NumPy 則提供數組運算和大量數值計算功能。適合結合真實數據問題練習，例如清洗一份 CSV、計算業務指標、處理缺失值，或完成一次 Exploratory Data Analysis。常用學習資源包括：
  - [pandas Getting Started](https://pandas.pydata.org/docs/getting_started/index.html)：Pandas 官方入門文檔，適合第一次系統瞭解 Series、DataFrame、數據讀取、篩選、合併和統計等核心操作。
  - [pandas User Guide](https://pandas.pydata.org/docs/user_guide/index.html)：更完整的官方文檔，可以在實際項目中作為查詢手冊。
  - [NumPy Learn](https://numpy.org/learn/)：NumPy 官方整理的學習入口，包含教程、課程和書籍資源。
  - [NumPy User Guide](https://numpy.org/doc/stable/user/index.html)：適合進一步理解 ndarray、索引、廣播、數據類型和數值計算。
  - [Kaggle Pandas](https://www.kaggle.com/learn/pandas)：以短練習為主，適合快速熟悉常用 Pandas 操作。
  - [Kaggle Data Cleaning](https://www.kaggle.com/learn/data-cleaning)：圍繞缺失值、日期、編碼等真實數據清洗問題練習 Pandas。
  - [LeetCode 30 Days of Pandas](https://leetcode.com/studyplan/30-days-of-pandas/)：以題目形式練習篩選、聚合、合併和數據處理，適合會在面試中考 Pandas 的崗位。

- **機器學習算法：** 準備 Data Science、Machine Learning、AI 等崗位時，需要理解常見算法，同時建立完整的機器學習流程，包括數據準備、特徵處理、模型選擇、訓練、評估、調參，以及 overfitting、data leakage、class imbalance 等常見問題。可以先建立整體框架，再根據目標崗位決定需要掌握到什麼深度。常用資源包括：
  - [Machine Learning Specialization — Andrew Ng / DeepLearning.AI](https://www.coursera.org/specializations/machine-learning-introduction)：適合機器學習入門，由 Andrew Ng 主講，共三門課程，從 Regression、Classification 開始，再覆蓋 Neural Networks、Decision Trees、Clustering、Recommender Systems 和 Reinforcement Learning 等內容。 :contentReference[oaicite:0]{index=0}
  - [Mathematics for Machine Learning and Data Science — DeepLearning.AI](https://www.coursera.org/specializations/mathematics-for-machine-learning-and-data-science)：如果線性代數、微積分、概率和統計基礎較弱，可以用於補充機器學習所需數學基礎。 :contentReference[oaicite:1]{index=1}
  - [Deep Learning Specialization — Andrew Ng / DeepLearning.AI](https://www.coursera.org/specializations/deep-learning)：適合已經掌握基礎機器學習、希望進一步學習 Neural Networks、CNN、Sequence Models 等深度學習內容的人。 :contentReference[oaicite:2]{index=2}
  - [IBM Machine Learning Professional Certificate](https://www.coursera.org/professional-certificates/ibm-machine-learning)：更側重實踐，包含 hands-on labs 和項目，適合希望通過項目進一步熟悉機器學習應用的人。 :contentReference[oaicite:3]{index=3}
  - [scikit-learn User Guide](https://scikit-learn.org/stable/user_guide.html)：Scikit-learn 官方文檔，可以作為算法和實現方式的索引，涵蓋 Supervised Learning、Unsupervised Learning、Model Selection、Preprocessing、Pipelines 等主題。
  - [Kaggle Intro to Machine Learning](https://www.kaggle.com/learn/intro-to-machine-learning)：適合在學習基礎概念後快速完成第一個機器學習項目。
  - [Kaggle Intermediate Machine Learning](https://www.kaggle.com/learn/intermediate-machine-learning)：進一步覆蓋 Missing Values、Categorical Variables、Pipelines、Cross-validation、XGBoost 和 Data Leakage 等實際問題。

- **Git 與 GitHub：** Git 是開發中常見的版本控制工具，用於記錄代碼變化、管理不同版本和多人協作；GitHub 則常用於代碼託管、協作和公開展示項目。對於 Software Engineering、Data Science、Machine Learning 等技術崗位，一個結構清楚的 GitHub 項目也可以成為能力證據。重點可以放在基本 Git Workflow、Branch、Merge、Pull Request、README 和項目結構上。常用資源包括：
  - [Pro Git](https://git-scm.com/book/en/v2)：Git 官方網站提供的完整免費電子書，從基本命令到 Branching、Remote Repository 等內容都有系統介紹。
  - [Git Reference](https://git-scm.com/docs)：Git 官方命令文檔，適合作為日常查詢工具。
  - [GitHub Skills](https://skills.github.com/)：GitHub 官方互動式課程，可以通過實際 Repository 學習 GitHub Flow、Pull Request、Merge Conflict、GitHub Actions 等操作。
  - [GitHub Docs — Get Started](https://docs.github.com/en/get-started)：GitHub 官方入門文檔，適合瞭解 Repository、Commit、Branch、Pull Request 等基本概念。
  - [GitHub Docs — About README](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes)：介紹如何編寫 README。對於求職項目，可以清楚説明項目解決的問題、使用的數據或技術、運行方式、主要結果和自己的貢獻。
  - [GitHub Docs — GitHub Flow](https://docs.github.com/en/get-started/using-github/github-flow)：介紹常見的 Branch → Commit → Pull Request → Review → Merge 協作流程。

  GitHub 的綠色貢獻圖本身不能直接説明工程能力。對於求職來説，一個能夠運行、結構清楚，並且通過 README 解釋清楚問題、方法和結果的項目，通常更容易成為面試中可以討論的能力證據。

## 比賽與項目證據

- **商賽：** 適合練習研究、商業判斷、方案表達和團隊協作。先看比賽主題與交付物是否和目標崗位相關，再決定投入。可以繼續閲讀[商賽準備](./business-competition.md)。
- **Kaggle：** 適合數據分析和機器學習實踐，也可以把公開 Notebook、方法説明和復盤變成作品證據。題目與規則以 [Kaggle Competitions](https://www.kaggle.com/competitions) 為準，也可以查看[Kaggle 競賽準備](./kaggle-competition.md)。
- **課程項目：** 不一定要重新開一個大項目。把已有課程作業補上問題背景、方法選擇、結果驗證和清晰説明，也可能比匆忙參加新活動更完整。

## 金融與專業資格

很多金融從業人員都會考專業資格，因此很容易產生“別人都有，我是不是也缺一個”的感覺。CFA、FRM 和 HKICPA QP 對應的知識、職業路徑與資格要求並不相同，也不一定必須要在入職前考完。先看崗位會不會使用，再決定是否加入你的求職 Path。

### 看看這些證書具體考核什麼

| 路徑 | 更貼近的內容 | 常見相關方向 |
| --- | --- | --- |
| CFA | 投資分析、估值、資產類別、組合管理與職業倫理 | 研究、資產管理、財富管理、部分投融資崗位 |
| FRM | 市場、信用、操作、流動性等金融風險的識別與管理 | 風險管理、模型驗證、市場與信用風險、風險諮詢 |
| HKICPA QP | 會計、財務報告、商業與專業判斷，加上實踐經驗 | 香港審計、會計、財務報告與相關專業服務 |

表格描述的是知識重心，不代表所有相關崗位都要求證書。具體 JD、僱主培訓路徑和資格政策優先級更高。

如果你決定要把某項證書加入你的求職路線當中，後續你會看到關於每個證書的獨立 note。在裏面，你可以依次確認適用崗位、考試結構、報名資格等信息。考試日期、費用和政策都可能變化，最終以官方頁面為準。
你也可以只學習你想投遞的崗位最需要的模塊，而暫時不報名參加考試，等參加實際工作之後，再決定是否考完專業資格。

- 投資與研究方向可以瞭解 **CFA**；風險方向可以瞭解 **FRM**；會計路徑可以瞭解 **HKICPA QP、CPA 或 [ACCA](https://www.accaglobal.com/gb/en/qualifications/glance/acca/overview.html)**。
- 量化金融方向還可能遇到 **[CQF](https://www.cqf.com/about-cqf/qualification/overview)**。它與短期刷題不同，需要單獨評估課程內容、費用、數學基礎和目標崗位認可度。

### 從招聘任務反推，而不是從知名度正推

讀目標崗位時，可以區分入職後會直接使用的知識、測試與面試內容、明確要求的資格路徑、preferred 加分項，以及只出於長期興趣的學習。如果崗位當前更需要 SQL、會計基礎、行業研究、客户溝通等，先補充與這些技能相關的證據可能更直接。
