# Application Trackers

A tracker should reduce memory load. It need not become a complex database; it only needs to show what you applied for, what happens next, and when action is due.

## Keep useful fields

Company, role, link, submission date, status, next step, and deadline are often enough. Add contacts, material versions, or notes only when useful.

## Use status to support decisions

Archive finished processes and highlight upcoming deadlines or follow-ups. A tracker should clarify the situation, not tell you that you have never applied enough.
