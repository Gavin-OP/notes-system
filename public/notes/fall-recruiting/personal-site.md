# 个人主页

个人主页是集中展示你专业形象和职业信息的页面，用来集中呈现你的职业发展方向、经历、项目和联系方式。它不同于项目集：项目集深入展示作品，而个人主页则负责把你的简历、LinkedIn、GitHub、文章和项目组织到同一个地方，提供一个全面的概览。

## 什么时候值得做

如果你的材料分散在多个平台，或者你申请的岗位特别关注作品、写作、技术实现与个人表达，那么个人主页会非常有帮助。如果目前你只有一份简历和一个项目，先把这些内容打磨好也完全可以，个人网站不是求职的必备项目。

## 首页核心要素

当招聘者快速浏览你的网站时，最好能一眼看懂：
*   你是谁，目前关注什么方向；
*   最值得看的经历或代表项目是什么；
*   你的能力有什么证据；
*   怎样查看简历或联系你。

首页可以由简短介绍、代表项目、经历摘要、简历入口和联系方式组成。其他更详细的内容再按需进入独立的页面。

## 优先信息层级与可访问性

请将信息层级的重要性放在视觉效果之前。每个项目先写一句结论，再提供图片和详情链接。导航名称保持直白，例如 About、Projects、Experience、Writing、Contact。动画、3D 效果和复杂滚动若拖慢加载速度或遮挡内容，反而会妨碍信息传达。

移动端适配至关重要。文字能否舒适阅读、按钮是否容易点击、图片是否溢出、导航是否能顺畅开关，这些都比炫酷效果更能影响真实的用户体验。同时，为确保网站对所有用户都易于访问，请考虑使用语义化的 HTML、为图片添加替代文本（alt text），并确保足够的颜色对比度。

## 选择搭建与发布方式

个人主页通常分成两步：先决定用什么方式搭建内容，再选择合适的发布方式。工具可以随时更换，真正值得长期维护的是你的内容结构、项目案例和个人信息。

### 先选择搭建方式

*   **[Notion](https://www.notion.com/) / 文档型页面：** 上手快，适合先整理经历、项目和文字内容，也方便持续更新。
*   **[Squarespace](https://www.squarespace.com/) / [Webflow](https://webflow.com/) 等网站生成器：** 提供模板和可视化编辑，适合希望快速做出完整个人网站，同时拥有更多排版自由度的人。
*   **AI / Vibe Coding：** 可以通过自然语言生成页面，再根据反馈持续调整布局、交互和内容。适合希望拥有更高自由度，或者想顺便尝试网页开发的人。完成后通常还需要把网站部署到线上，才能生成可以分享给招聘者的链接。
*   **自己编写网站：** 如果熟悉 HTML、CSS、JavaScript 或 React 等技术，也可以从头搭建。对于软件开发岗位，这个过程本身也可以成为项目能力的一部分。

### 再选择发布方式

如果使用 Squarespace、Webflow 这类平台，通常可以直接在平台内发布网站。

如果通过 Vibe Coding 或自己写代码生成网站，则可以部署到：

*   **[GitHub Pages](https://pages.github.com/)：** 适合静态个人主页和项目集，可以直接从 GitHub 仓库发布。
*   **[Vercel](https://vercel.com/)：** 适合 React、Next.js 等现代前端项目，也支持连接 GitHub 仓库后自动部署。
*   **[Netlify](https://www.netlify.com/)：** 适合静态网站和前端项目，可以连接代码仓库并持续更新部署。

## 可信、隐私与安全

*   公开邮箱可以使用专门的求职邮箱，避免泄露私人信息；
*   简历下载版删除不需要公开的住址、电话或证件信息；
*   分享项目数据前，务必确认权限并进行脱敏处理，避免泄露机密；
*   外部链接使用清楚的文字描述，并定期检查是否失效；
*   自定义域名、HTTPS 加密和访问统计均为可选，但能显著提升专业度和安全性；
*   切勿在网页代码中直接放置 API Key、密码或私密文件。

## 发布前检查与维护

发布前，请进行一次彻底的检查。在手机和电脑上分别测试，从首页导航至项目、简历和联系方式。随后，将链接分享给朋友，请他们描述你网站传达的信息重点和视觉效果，提供建议。

保持网站内容的时效性。定期检查失效链接，并更新你的进展。

如果选择 GitHub Pages，可以参考 [GitHub 官方 Quickstart](https://docs.github.com/en/pages/quickstart)。它支持从仓库分支发布静态网站，也适合以后逐步更新。
