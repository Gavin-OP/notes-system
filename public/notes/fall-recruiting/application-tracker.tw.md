# Application Tracker

Tracker 的作用是減輕記憶負擔。它不用變成複雜資料庫，只要能回答：申請了甚麼、下一步是甚麼、何時需要行動。

## 保留真正有用的欄位

公司、職位、連結、提交日期、目前狀態、下一節點和截止時間通常已經足夠。需要時才補聯絡人、材料版本和簡短備註。

## 讓狀態服務於決定

定期清理已結束流程，標出即將截止和等待跟進的項目。Tracker 應幫你看清局面，而不是提醒你申請得不夠多。
