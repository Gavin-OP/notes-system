# Application Batch Planning

批量申請的價值是穩定增加被看見的機會，而不是讓申請數量成為新的 KPI。把相近職位分組，可以減少重複準備，亦能為重要機會保留精力。

## 按相似度分批

將職位按職責、材料和截止時間分組。共用可靠底稿，再針對關鍵要求作必要調整；明顯不合適的職位不必勉強加入。

## 為測試和面試留容量

申請之後可能變成測試、電話和面試。每批留出處理後續流程的空間，再按回應和體驗調整節奏。
