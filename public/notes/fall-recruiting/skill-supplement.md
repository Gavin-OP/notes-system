# 技能补充：按岗位选择你的技能包

技能准备是求职 Path 的一条副线。LeetCode、投行面试题、竞赛、数据工具和金融证书都可以出现在这条线上，但它们不是同一种投入，也不是人人都要收集的徽章。

## 先判断自己缺的是哪一种证据

| 类型 | 更常解决什么问题 | 可以留下什么 |
| --- | --- | --- |
| 岗位筛选题库 | 应对明确的笔试或面试考察 | 做题记录、知识框架、面试表现 |
| 工具与项目 | 证明自己能用常见工具解决问题 | GitHub 项目、分析报告、可运行代码 |
| 比赛 | 在实习经历较少时补充协作和项目证据 | 作品、排名、过程复盘、团队故事 |
| 专业资格 | 系统学习某个专业领域，或满足特定职业路径要求 | 考试进度、知识体系、正式资格 |

先从目标岗位的 JD、在线测试说明、面试流程和真实反馈找信号。看到同一要求反复出现，再决定是否投入；如果只因为“别人都在学”而开一条新线，最容易得到的技能可能是同时打开很多网页。

## 岗位筛选与面试题库

- **LeetCode：** 适合流程明确考算法、数据结构、代码或 SQL 的岗位。SQL 可以先看 [LeetCode SQL 50](https://leetcode.com/studyplan/top-sql-50/)；算法题是否需要刷、刷到什么程度，仍由岗位流程决定。
- **投行 400 问、绿皮书等面试资料：** 更像针对特定招聘流程的知识题库，而不是通用金融能力。先确认目标岗位会考什么，再通过正版出版物、学校资源或官方招聘资料准备。本平台不提供未经授权的下载链接。

## 数据、机器学习与项目工具

- **Pandas / NumPy：** 数据分析与科学计算的常用工具。可以从 [pandas Getting Started](https://pandas.pydata.org/docs/getting_started/index.html) 和 [NumPy Learn](https://numpy.org/learn/) 开始，把练习放进一个真实数据问题里。
- **机器学习算法：** 与其先背一长串模型名称，不如围绕数据准备、模型选择、评估和常见误区建立框架。[scikit-learn User Guide](https://scikit-learn.org/stable/user_guide.html)可以作为官方索引。
- **Git 与 GitHub：** Git 帮助记录和协作开发，GitHub 可以展示公开项目、README、提交记录和协作方式。可以使用 [Pro Git](https://git-scm.com/book/en/v2) 和 [GitHub Skills](https://skills.github.com/) 入门。绿色贡献图不是招聘保证；一个说明清楚、能够运行的项目通常更有解释力。

## 比赛与项目证据

- **商赛：** 适合练习研究、商业判断、方案表达和团队协作。先看比赛主题与交付物是否和目标岗位相关，再决定投入。可以继续阅读[商赛准备](./business-competition.md)。
- **Kaggle：** 适合数据分析和机器学习实践，也可以把公开 Notebook、方法说明和复盘变成作品证据。题目与规则以 [Kaggle Competitions](https://www.kaggle.com/competitions) 为准，也可以查看[Kaggle 竞赛准备](./kaggle-competition.md)。
- **课程项目：** 不一定要重新开一个大项目。把已有课程作业补上问题背景、方法选择、结果验证和清晰说明，也可能比匆忙参加新活动更完整。

## 金融与专业资格

证书属于更长周期的选择，不能只用“含金量高不高”判断。可以先看目标岗位是否明确认可、课程是否补足当前知识、考试窗口是否挤压申请，以及自己是否满足报考和工作经验要求。

- 投资与研究方向可以了解 **CFA**；风险方向可以了解 **FRM**；会计路径可以了解 **HKICPA QP、CPA 或 [ACCA](https://www.accaglobal.com/gb/en/qualifications/glance/acca/overview.html)**。
- 量化金融方向还可能遇到 **[CQF](https://www.cqf.com/about-cqf/qualification/overview)**。它与短期刷题不同，需要单独评估课程内容、费用、数学基础和目标岗位认可度。
- 想比较现有证书分支，可以继续阅读[金融证书怎么选](./finance-knowledge-certificates.md)。

## 最后只做一个选择

问自己：目标岗位最近会用什么方式验证我？如果答案是代码测试，就先练题；如果缺少作品，就做项目或比赛；如果职业路径明确要求资格，再研究证书。暂时没有清晰信号时，先把时间留给岗位研究、材料和真实申请也完全合理。
