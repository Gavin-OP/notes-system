# 技能补充

技能准备是求职 Path 的一条副线。它可以和岗位研究、简历准备同时进行，却不需要变成一张人人照抄的清单。

## 先从岗位信号出发

值得优先补的内容，通常会在 JD、在线测试或面试反馈里反复出现。例如，技术与数据岗位可能要求算法或 SQL；部分金融岗位会关注投资、风险或会计知识。看到明确而重复的信号，再把对应分支加入 Path，方向会更清楚。

## LeetCode 与金融证书解决的是不同问题

- **LeetCode** 更适合准备算法题、SQL 题和有明确技术考察的招聘流程。
- **金融证书** 更像一组需要单独评估的长期选择。CFA、FRM 与 HKICPA QP 面向的知识和职业路径不同，是否报名应结合目标岗位、考试窗口、投入时间与资格要求。

技能副线不需要一次全部开启。先处理最接近下一次投递、测试或面试的部分，其余内容可以等真实反馈出现后再加入。

## 怎样判断是否继续投入

学习一段时间后，可以回到三个问题：岗位真的会用到吗？现在能否形成可展示或可考察的证据？它会不会挤压更紧迫的投递和面试准备？答案会帮助你决定继续、暂停，或换一种更直接的准备方式。
