# 技能补充：按岗位选择你的技能包

LeetCode、投行面试题、竞赛、数据分析工具、金融证书……这些技能的准备，是求职道路上的一条支线。其中一些需要长期积累，学习和培训过程可能会从正式求职前几年开始，一直延续到入职以后。每一项技能都需要投入时间和精力，因此，比起尽可能多地学习，更重要的是根据目标岗位判断：自己究竟需要在求职阶段补充哪些技能，以及哪些技能值得优先投入。

## 先判断自己缺的是哪一种证据

| 类型 | 更常解决什么问题 | 可以留下什么 |
| --- | --- | --- |
| 岗位筛选与面试题库 | 应对明确的笔试或面试考察 | 做题记录、面试表现 |
| 工具与项目 | 证明自己能用常见工具解决问题 | GitHub 项目、分析报告 |
| 比赛 | 在实习经历较少时补充协作和项目证据 | 作品、排名、团队故事 |
| 专业资格 | 系统学习某个专业领域，或满足特定职业路径要求 | 考试进度、正式资格 |

先从目标岗位的 JD、笔试/面试流程说明和求职者真实反馈当中找信号。看到同一要求反复出现，再决定是否投入；如果只因为“别人都在学”而开始技能补充的支线，最容易得到的技能可能是同时打开很多网页。

## 岗位筛选与面试题库

- **LeetCode：** 适合流程明确考算法、数据结构、代码或 SQL 的岗位。算法题是否需要刷、刷到什么程度，仍由目标岗位和面试流程决定。常用题库包括：
  - [LeetCode 75](https://leetcode.com/studyplan/leetcode-75/)：75 道高频基础题，适合用 1–3 个月建立常见算法题型框架。
  - [Top Interview 150](https://leetcode.com/studyplan/top-interview-150/)：覆盖范围更完整，适合系统准备技术面试。
  - [Top 100 Liked](https://leetcode.com/studyplan/top-100-liked/)：LeetCode 社区中评价较高的 100 道题，适合补充常见面试题型。
  - [Blind 75](https://neetcode.io/practice/practice/blind75)：经典的 75 道算法面试题，适合快速覆盖核心题型。
  - [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)：在 Blind 75 基础上扩展到 150 题，并按照 Arrays、Trees、Graphs、Dynamic Programming 等主题分类，适合系统刷题。
  - [SQL 50](https://leetcode.com/studyplan/top-sql-50/)：50 道基础到中等难度 SQL 题，适合 Data Analyst、BI、Data Science 等会考 SQL 的岗位。
  - [Advanced SQL 50](https://leetcode.com/studyplan/premium-sql-50/)：覆盖基础到进阶 SQL 的高频题目，适合需要更深入 SQL 面试准备的人。
  - [30 Days of Pandas](https://leetcode.com/studyplan/30-days-of-pandas/)：针对 Pandas 常见面试内容，适合数据分析和部分数据科学岗位。
  - [LeetCode Study Plans](https://leetcode.com/studyplan/)：LeetCode 官方全部学习计划的入口，可以再按目标岗位和技能选择对应题库。

- **投行面试题、400 Questions、Red Book 等面试资料：** 更像针对 Investment Banking、Private Equity 等特定招聘流程的知识题库，通常集中在 Accounting、Valuation、DCF、M&A、LBO、Technical Questions 和 Behavioral Questions。不同岗位、公司和招聘阶段的考察重点差异较大，因此可以先确认目标岗位的面试流程，再选择对应材料。常见的正版或官方公开资源包括：
  - [Breaking Into Wall Street – Investment Banking Interview Guide / 400 Questions](https://breakingintowallstreet.com/investment-banking-interview-guide/)：经典的 Investment Banking 面试准备资料，官方 Interview Guide 中包含其 400 Questions Guide，覆盖常见 Technical 和 Behavioral Questions。
  - [Wall Street Prep – Investment Banking Interview Guide / The Red Book](https://www.wallstreetprep.com/self-study-programs/the-red-book/)：Wall Street Prep 官方面试题库，包含大量 Investment Banking Technical 和 Behavioral Questions，适合更系统地准备投行面试。
  - [Wall Street Prep – Investment Banking Interview Questions](https://www.wallstreetprep.com/knowledge/top-10-investment-banking-interview-questions/)：免费的常见投行面试题整理，涵盖 Valuation、DCF、Accounting 等核心 Technical Questions。
  - [Wall Street Prep – Investment Banking Interview Guide](https://www.wallstreetprep.com/knowledge/investment-banking-interview/)：从整体流程介绍 Investment Banking Interview，并梳理 Behavioral 和 Technical Questions 的主要准备方向。
  - [Wall Street Prep – M&A Interview Questions](https://www.wallstreetprep.com/knowledge/ma-interview-questions/)：集中准备 Merger Model、Accretion / Dilution 和 M&A 相关问题。
  - [Wall Street Prep – Private Equity Interview Questions](https://www.wallstreetprep.com/knowledge/25-private-equity-interview-questions-you-must-know/)：适合进一步申请 Private Equity 的同学，涵盖 PE Technical Questions 和常见面试主题。
  - [Breaking Into Wall Street – M&A Interview Questions](https://breakingintowallstreet.com/kb/ma-and-merger-models/ma-interview-questions/)：官方免费教程，集中讲解 Merger Model 和 M&A 面试中的常见问题。
  - [Breaking Into Wall Street – LBO Interview Questions](https://breakingintowallstreet.com/kb/leveraged-buyouts-and-lbo-models/lbo-interview-questions/)：适合准备 LBO、Private Equity 及部分 Investment Banking Technical Interview。
  - [Breaking Into Wall Street – Equity Value & Enterprise Value Interview Questions](https://breakingintowallstreet.com/kb/equity-value-enterprise-value/equity-value-and-enterprise-value-interview-questions-what-to-expect/)：针对 Equity Value、Enterprise Value 及相关 Valuation Questions 的专题练习。
  - [Breaking Into Wall Street – Behavioral Interview Questions](https://breakingintowallstreet.com/kb/interviews/investment-banking-behavioral-questions/)：集中准备 Why Investment Banking、Walk Me Through Your Resume、团队经历等 Behavioral Questions。
  - [CFI – Investment Banking Interview Questions](https://corporatefinanceinstitute.com/resources/career/real-investment-banking-interview-questions-form/)：CFI 官方整理的投行面试题，可以用于补充 Accounting、Valuation 和情景类问题。
  - [Macabacus – Learn Finance](https://macabacus.com/learn)：提供 Operating Model、M&A Model、LBO Model 等公开学习材料，更适合理解面试题背后的 Financial Modeling 知识，而不只是背答案。

## 数据、机器学习与项目工具

- **Pandas / NumPy：** 数据分析与科学计算中最常用的 Python 工具之一。Pandas 主要用于表格数据的读取、清洗、转换和分析，NumPy 则提供数组运算和大量数值计算功能。适合结合真实数据问题练习，例如清洗一份 CSV、计算业务指标、处理缺失值，或完成一次 Exploratory Data Analysis。常用学习资源包括：
  - [pandas Getting Started](https://pandas.pydata.org/docs/getting_started/index.html)：Pandas 官方入门文档，适合第一次系统了解 Series、DataFrame、数据读取、筛选、合并和统计等核心操作。
  - [pandas User Guide](https://pandas.pydata.org/docs/user_guide/index.html)：更完整的官方文档，可以在实际项目中作为查询手册。
  - [NumPy Learn](https://numpy.org/learn/)：NumPy 官方整理的学习入口，包含教程、课程和书籍资源。
  - [NumPy User Guide](https://numpy.org/doc/stable/user/index.html)：适合进一步理解 ndarray、索引、广播、数据类型和数值计算。
  - [Kaggle Pandas](https://www.kaggle.com/learn/pandas)：以短练习为主，适合快速熟悉常用 Pandas 操作。
  - [Kaggle Data Cleaning](https://www.kaggle.com/learn/data-cleaning)：围绕缺失值、日期、编码等真实数据清洗问题练习 Pandas。
  - [LeetCode 30 Days of Pandas](https://leetcode.com/studyplan/30-days-of-pandas/)：以题目形式练习筛选、聚合、合并和数据处理，适合会在面试中考 Pandas 的岗位。

- **机器学习算法：** 准备 Data Science、Machine Learning、AI 等岗位时，需要理解常见算法，同时建立完整的机器学习流程，包括数据准备、特征处理、模型选择、训练、评估、调参，以及 overfitting、data leakage、class imbalance 等常见问题。可以先建立整体框架，再根据目标岗位决定需要掌握到什么深度。常用资源包括：
  - [Machine Learning Specialization — Andrew Ng / DeepLearning.AI](https://www.coursera.org/specializations/machine-learning-introduction)：适合机器学习入门，由 Andrew Ng 主讲，共三门课程，从 Regression、Classification 开始，再覆盖 Neural Networks、Decision Trees、Clustering、Recommender Systems 和 Reinforcement Learning 等内容。 :contentReference[oaicite:0]{index=0}
  - [Mathematics for Machine Learning and Data Science — DeepLearning.AI](https://www.coursera.org/specializations/mathematics-for-machine-learning-and-data-science)：如果线性代数、微积分、概率和统计基础较弱，可以用于补充机器学习所需数学基础。 :contentReference[oaicite:1]{index=1}
  - [Deep Learning Specialization — Andrew Ng / DeepLearning.AI](https://www.coursera.org/specializations/deep-learning)：适合已经掌握基础机器学习、希望进一步学习 Neural Networks、CNN、Sequence Models 等深度学习内容的人。 :contentReference[oaicite:2]{index=2}
  - [IBM Machine Learning Professional Certificate](https://www.coursera.org/professional-certificates/ibm-machine-learning)：更侧重实践，包含 hands-on labs 和项目，适合希望通过项目进一步熟悉机器学习应用的人。 :contentReference[oaicite:3]{index=3}
  - [scikit-learn User Guide](https://scikit-learn.org/stable/user_guide.html)：Scikit-learn 官方文档，可以作为算法和实现方式的索引，涵盖 Supervised Learning、Unsupervised Learning、Model Selection、Preprocessing、Pipelines 等主题。
  - [Kaggle Intro to Machine Learning](https://www.kaggle.com/learn/intro-to-machine-learning)：适合在学习基础概念后快速完成第一个机器学习项目。
  - [Kaggle Intermediate Machine Learning](https://www.kaggle.com/learn/intermediate-machine-learning)：进一步覆盖 Missing Values、Categorical Variables、Pipelines、Cross-validation、XGBoost 和 Data Leakage 等实际问题。

- **Git 与 GitHub：** Git 是开发中常见的版本控制工具，用于记录代码变化、管理不同版本和多人协作；GitHub 则常用于代码托管、协作和公开展示项目。对于 Software Engineering、Data Science、Machine Learning 等技术岗位，一个结构清楚的 GitHub 项目也可以成为能力证据。重点可以放在基本 Git Workflow、Branch、Merge、Pull Request、README 和项目结构上。常用资源包括：
  - [Pro Git](https://git-scm.com/book/en/v2)：Git 官方网站提供的完整免费电子书，从基本命令到 Branching、Remote Repository 等内容都有系统介绍。
  - [Git Reference](https://git-scm.com/docs)：Git 官方命令文档，适合作为日常查询工具。
  - [GitHub Skills](https://skills.github.com/)：GitHub 官方互动式课程，可以通过实际 Repository 学习 GitHub Flow、Pull Request、Merge Conflict、GitHub Actions 等操作。
  - [GitHub Docs — Get Started](https://docs.github.com/en/get-started)：GitHub 官方入门文档，适合了解 Repository、Commit、Branch、Pull Request 等基本概念。
  - [GitHub Docs — About README](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes)：介绍如何编写 README。对于求职项目，可以清楚说明项目解决的问题、使用的数据或技术、运行方式、主要结果和自己的贡献。
  - [GitHub Docs — GitHub Flow](https://docs.github.com/en/get-started/using-github/github-flow)：介绍常见的 Branch → Commit → Pull Request → Review → Merge 协作流程。

  GitHub 的绿色贡献图本身不能直接说明工程能力。对于求职来说，一个能够运行、结构清楚，并且通过 README 解释清楚问题、方法和结果的项目，通常更容易成为面试中可以讨论的能力证据。

## 比赛与项目证据

- **商赛：** 适合练习研究、商业判断、方案表达和团队协作。先看比赛主题与交付物是否和目标岗位相关，再决定投入。可以继续阅读[商赛准备](./business-competition.md)。
- **Kaggle：** 适合数据分析和机器学习实践，也可以把公开 Notebook、方法说明和复盘变成作品证据。题目与规则以 [Kaggle Competitions](https://www.kaggle.com/competitions) 为准，也可以查看[Kaggle 竞赛准备](./kaggle-competition.md)。
- **课程项目：** 不一定要重新开一个大项目。把已有课程作业补上问题背景、方法选择、结果验证和清晰说明，也可能比匆忙参加新活动更完整。

## 金融与专业资格

很多金融从业人员都会考专业资格，因此很容易产生“别人都有，我是不是也缺一个”的感觉。CFA、FRM 和 HKICPA QP 对应的知识、职业路径与资格要求并不相同，也不一定必须要在入职前考完。先看岗位会不会使用，再决定是否加入你的求职 Path。

### 看看这些证书具体考核什么

| 路径 | 更贴近的内容 | 常见相关方向 |
| --- | --- | --- |
| CFA | 投资分析、估值、资产类别、组合管理与职业伦理 | 研究、资产管理、财富管理、部分投融资岗位 |
| FRM | 市场、信用、操作、流动性等金融风险的识别与管理 | 风险管理、模型验证、市场与信用风险、风险咨询 |
| HKICPA QP | 会计、财务报告、商业与专业判断，加上实践经验 | 香港审计、会计、财务报告与相关专业服务 |

表格描述的是知识重心，不代表所有相关岗位都要求证书。具体 JD、雇主培训路径和资格政策优先级更高。

如果你决定要把某项证书加入你的求职路线当中，后续你会看到关于每个证书的独立 note。在里面，你可以依次确认适用岗位、考试结构、报名资格等信息。考试日期、费用和政策都可能变化，最终以官方页面为准。
你也可以只学习你想投递的岗位最需要的模块，而暂时不报名参加考试，等参加实际工作之后，再决定是否考完专业资格。

- 投资与研究方向可以了解 **CFA**；风险方向可以了解 **FRM**；会计路径可以了解 **HKICPA QP、CPA 或 [ACCA](https://www.accaglobal.com/gb/en/qualifications/glance/acca/overview.html)**。
- 量化金融方向还可能遇到 **[CQF](https://www.cqf.com/about-cqf/qualification/overview)**。它与短期刷题不同，需要单独评估课程内容、费用、数学基础和目标岗位认可度。

### 从招聘任务反推，而不是从知名度正推

读目标岗位时，可以区分入职后会直接使用的知识、测试与面试内容、明确要求的资格路径、preferred 加分项，以及只出于长期兴趣的学习。如果岗位当前更需要 SQL、会计基础、行业研究、客户沟通等，先补充与这些技能相关的证据可能更直接。
